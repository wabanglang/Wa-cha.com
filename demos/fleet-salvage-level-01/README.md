# WA-CHA Fleet Salvage Level 01

Open index.html offline. Destroy enemies; fly into glowing caches to collect salvage. Pause to upgrade the selected ship. Upgrades are per ship and persist in browser localStorage. Restart resets the mission but retains collected resources and upgrades.

Enemy drops: interceptor → coils/ion/parts; TIE fighter → capacitors/parts; bomber → alloy/armor/parts. Three upgrade tracks: shield capacity, hull capacity, and firing cadence/damage. Each level costs increasing quantities of recipe materials. Five levels maximum. All art is HTML/CSS.

Controls: arrows/WASD, Space to fire, Shift for ALT, drag on stage; PAUSE enables purchasing. Browser playthrough not independently verified.
